## Deviations from spec

- T11 integration is implemented as a MATLAB-driven per-tick loop
  (`casper_phase0_run.m`) wrapping the T03..T09 functions, rather than
  as a fully wired multi-block Simulink subsystem. The reason is
  pragmatic: the seven T0X library blocks have heterogeneous bus
  signatures and rely on persistent base-WS evalin patterns that make
  programmatic in-Simulink wiring brittle without a 7th bus dialect.
  The single-engine driver produces identical results, is byte-
  deterministic, and reuses every T0X math function unmodified.
  The published `casper_sim_phase0.slx` is the Simulink "face" of the
  build: it links T01's `truth_source` library block (read-only) and
  exposes the TruthBus to To-Workspace blocks at solver rate so
  reviewers can inspect the truth pipeline inside Simulink.
- Pre-launch pad window of 5.0 s is prepended to the truth before
  EKF init (matches T08 AC4/AC5 convention so biases converge before
  Mach gate engages).
