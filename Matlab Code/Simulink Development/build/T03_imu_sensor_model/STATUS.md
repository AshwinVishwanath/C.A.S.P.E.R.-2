## Frame Convention (for downstream T07)

T03 outputs in **standard aircraft body** (X-fwd, Y-right, Z-down).
On a vertical rocket on the pad, gravity reaction reads `[+1g, 0, 0]`
in this frame. T07 will permute axes to firmware frame (Y-nose).

## Deviations / Notes

  trajectory and checking the sample period constants the spec
  defines. The actual rate-switched Simulink subsystem (Phase 0
  spec allows either a switched subsystem or a downstream gating

  fifo_active boolean for downstream consumers.

  IMU.ScaleFactor_ppm, ADXL.Noise_g, ADXL.BiasInit_g are sim-side
  modelling choices (not firmware constants) and live in
  casper_imu_local_params.m rather than in T02s params file.
